Política de privacidad

Última actualización: 19 de noviembre de 2026

1. Qué datos se usan

Al conectar una cuenta, TopGTA recibe de la plataforma un permiso de acceso (token) y datos básicos del perfil (identificador, nombre de usuario y foto). En TikTok se usan los permisos user.info.basic y video.publish.

2. Para qué se usan

Únicamente para mostrar qué cuenta está conectada y para publicar los videos que el usuario aprueba. No se leen mensajes, seguidores ni contenido privado.

3. Dónde se guardan

Todo se guarda en el computador del usuario. Los tokens se almacenan cifrados. TopGTA no tiene servidores propios que reciban estos datos.

4. Con quién se comparten

Con nadie. No se venden ni se ceden datos a terceros. Los videos solo se envían a la plataforma en la que el usuario decide publicarlos.

5. Borrado

Al desconectar una cuenta en TopGTA se borra su token. El usuario también puede revocar el acceso desde la configuración de seguridad de cada plataforma.

6. Contacto

Mediante github.com/IngJames1992.

Privacy Policy (English summary)

When an account is connected, TopGTA receives an access token and basic profile info (ID, username, avatar); on TikTok it uses the user.info.basic and video.publish scopes. Data is used only to show the connected account and publish videos the user approves. Everything is stored encrypted on the user's own computer; there are no TopGTA servers. No data is sold or shared. Disconnecting an account deletes its token, and access can be revoked from each platform's settings.
